# v8.6.0 implementation record

Date: 2026-08-12
Status: release candidate

## Scope

- Promote Python, npm, mobile, Windows launcher, projection, and workflow
  identity from `8.6.0-beta.3` to stable `8.6.0`.
- Publish the existing Linux, macOS, Android, Sidebar, and npm products.
- Attach the isolated Windows x64 ZIP to the stable GitHub Release while
  retaining beta support semantics.
- Include Pi native-session recovery and the project-scoped tmux socket fix
  accumulated since `v8.5.7`.

## Evidence entering final gates

- `v8.6.0-beta.3` Windows Server 2022 workflow passed native Python/Rust tests,
  PE/ZIP build, PowerShell archive installation, installed launcher smoke,
  upload, and downloaded-asset SHA256 verification.
- Cross Platform and CCBD real-platform workflows passed on the beta.3 source
  commit for Ubuntu, macOS, and WSL.
- Stable publication remains gated on synchronized version checks, bilingual
  release-note validation, local regression suites, package dry-run, immutable
  tag preflight, and post-publication asset/registry verification.

## Support boundary

`v8.6.0` is a stable CCB version. The Windows ZIP remains beta and does not
claim real GUI/provider qualification beyond the recorded Windows runner gates.
