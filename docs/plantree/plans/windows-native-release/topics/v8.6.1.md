# v8.6.1 publication record

Date: 2026-08-12
Status: published

## Scope

- Publish the audited Mobile Provider control plane, direct terminal launcher,
  customizable terminal shortcuts, built-in `ccb-compact`, and complete Config
  UI Role catalog.
- Refresh the WeChat community QR image and README cache keys.
- Preserve the stable Linux, macOS, Android, Sidebar, and npm release lanes
  while continuing to attach the isolated Windows x64 beta artifact.

## Audit repairs before publication

- Bound Mobile Provider-mutation idempotency to the exact project and Agent so
  identical payloads cannot reuse another target's cached result.
- Split compound terminal input frames into validated literal and key actions,
  preserving Unicode text and key order while rejecting an invalid frame before
  any partial Pane write.
- Restored Python 3.10 TOML test compatibility and made Herdr Windows fixtures
  declare x64 explicitly when GitHub's `macos-latest` runner is ARM64. The
  production Windows x64 gate remains fail-closed.
