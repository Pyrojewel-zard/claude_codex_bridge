# v8.6.0-beta.3 implementation record

Date: 2026-08-11

## Delta from beta.2

- `Confirm-HerdrReady` now treats `-Yes` and
  `CCB_INSTALL_ASSUME_YES=1` as explicit acknowledgement of the same guarded
  continuation offered by the interactive missing-Herdr prompt.
- The installer still warns that normal CCB startup requires Herdr. The CI
  lane may continue without Herdr only because it exercises the documented
  safe `--print-version` and `--help` surfaces.
- The fallback interactive prompt casts `Read-Host` to a string before
  trimming, so redirected input cannot cause a null-method exception.
- Preserved the failed `v8.6.0-beta.2` tag and Actions evidence.
