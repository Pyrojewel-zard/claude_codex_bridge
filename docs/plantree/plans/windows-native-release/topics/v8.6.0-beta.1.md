# v8.6.0-beta.1 implementation record

Date: 2026-08-11

## Changes

- `install.ps1` is a thin entrypoint; the implementation lives only under the
  Windows platform folder.
- The Windows builder is independent of the shared Linux/macOS builder and
  produces a ZIP plus checksum on a native Windows x64 runner.
- `ccb.exe`, `ask.exe`, `autonew.exe`, and `ctx-transfer.exe` are native Rust
  launchers. They execute the packaged Python entrypoints and preserve exit
  status; the beta therefore declares Python as a prerequisite.
- Herdr runtime modules moved under `lib/platforms/windows/herdr/`; Windows TCP
  transport and release projections have equivalent Windows-owned locations.

## Evidence status

- Local platform-neutral gates: passed. The isolated Windows release suite and
  adjacent TCP/Herdr regressions passed 462 tests with one environment skip;
  an additional deterministic merge-regression set passed 218 tests. Python
  compile, workflow YAML parsing, shell syntax, version identity, and
  release-surface freshness checks also passed. Restored reconnect coverage
  passed 63 tests and four subtests.
- Native PE build: pending GitHub Windows runner.
- PowerShell archive installation: pending GitHub Windows runner.
- Real GUI/provider qualification: pending after prerelease publication.

## Non-goals

- No npm Windows route.
- No Linux/macOS/mobile release for this tag.
- No claim that the ZIP is self-contained or signed.
