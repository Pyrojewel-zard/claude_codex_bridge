# v8.6.0-beta.2 — Native Windows x64 beta

Released: 2026-08-11

## English

### What changed since beta.1

This Windows-only test release fixes the artifact builder failure discovered by
the immutable `v8.6.0-beta.1` Actions run. The native Windows Python and Rust
tests passed in beta.1, but packaging stopped before installation or release
creation because its allowlist still required a nonexistent `commands/`
directory. Beta.2 removes that stale entry and adds a regression check for all
default payload directories. It also fixes a PR #293 cross-platform regression:
auto-selected tmux backends are now rebound to the current project's socket
instead of reusing a process-global cached backend. This restores project
lifecycle startup on Linux, macOS, and WSL without changing the Herdr path on
native Windows.

No `v8.6.0-beta.1` GitHub Release was created, and its tag was not moved.

### Included

- `ccb-windows-x86_64.zip` and its `.sha256` sidecar.
- Native PE launchers for `ccb`, `ask`, `autonew`, and `ctx-transfer`.
- A PowerShell installer that validates the optional archive checksum and
  payload structure, creates an install-local Python environment, installs the
  runtime dependencies, and smoke-checks `ccb.exe`.
- Windows-owned Herdr, TCP transport, installer, launcher, packaging, tooling,
  and documentation under `lib/platforms/windows/` and `platforms/windows/`.

### Install for testing

Download both Windows assets, compare the checksum, and then run:

```powershell
Get-FileHash .\ccb-windows-x86_64.zip -Algorithm SHA256
Get-Content .\ccb-windows-x86_64.zip.sha256
Expand-Archive .\ccb-windows-x86_64.zip -DestinationPath .\ccb-windows-beta
cd .\ccb-windows-beta\ccb-windows-x86_64
.\install.ps1 install -Yes
ccb --print-version
```

### Prerequisites and limits

- Native Windows x64, Python 3.10+, WezTerm, Git Bash, and Herdr 0.8.0 or newer.
- The ZIP is not fully self-contained; the native launcher runs the packaged
  Python source using the installer-created environment.
- `ccb update` remains diagnostic-only for this beta. Install a later beta by
  downloading and rerunning its validated `install.ps1`.
- The binaries are unsigned and may trigger a Windows SmartScreen warning.
- This prerelease does not publish or replace npm, Linux, macOS, sidebar, or
  Android artifacts.

### Publication gate

The GitHub prerelease is created only after the Windows 2022 workflow passes
native tests, builds PE binaries and the ZIP, installs from that ZIP with
PowerShell, and executes the installed `ccb.exe` smoke checks.

## 中文

### 相比 beta.1 的修复

这是 Windows 专用测试版本，修复了不可变标签 `v8.6.0-beta.1` 在 Actions 中
发现的打包问题。beta.1 的 Windows Python 与 Rust 原生测试已经通过，但打包清单
仍要求一个不存在的 `commands/` 目录，因此在安装和创建 Release 之前被正确阻断。
beta.2 删除了该过期目录，并新增“默认 payload 目录必须全部真实存在”的回归测试。
同时，本版修复了 PR #293 引入的跨平台回归：自动选择 tmux 后，会重新绑定到当前
项目自己的 socket，不再复用进程级缓存 backend。Linux、macOS 与 WSL 的项目生命周期
启动因此恢复正常，原生 Windows 的 Herdr 路径不受影响。

`v8.6.0-beta.1` 没有创建 GitHub Release，其标签也没有被移动。

### 包含内容

- `ccb-windows-x86_64.zip` 及对应的 `.sha256` 文件。
- `ccb`、`ask`、`autonew`、`ctx-transfer` 的原生 PE 启动器。
- PowerShell 安装器：校验可选的压缩包 SHA256 和 payload 结构，创建安装目录内的
  Python 环境，安装运行依赖，并对 `ccb.exe` 执行冒烟检查。
- Windows 专属的 Herdr、TCP transport、installer、launcher、packaging、工具与文档，
  分别位于 `lib/platforms/windows/` 和 `platforms/windows/`。

```powershell

```

### 前置条件与限制

- 原生 Windows x64、Python 3.10+、WezTerm、Git Bash、Herdr 0.8.0 或更高版本。
- ZIP 并非完全自包含；原生启动器通过安装器创建的环境运行包内 Python 源码。
- 本 Beta 的 `ccb update` 仍为仅诊断模式；升级后续 Beta 时需重新下载并运行其

- 二进制尚未签名，Windows 可能显示 SmartScreen 警告。
- 本预发布不会发布或替换 npm、Linux、macOS、Sidebar 或 Android 产物。

### 发布门禁

只有 Windows 2022 工作流完成原生测试、PE 与 ZIP 构建、PowerShell 解包安装，并
通过已安装 `ccb.exe` 的冒烟检查后，才会创建 GitHub Prerelease。
