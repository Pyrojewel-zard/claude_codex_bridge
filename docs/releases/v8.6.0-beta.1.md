# v8.6.0-beta.1 — Native Windows x64 beta

Released: 2026-08-11

## English

### What this prerelease is for

This is a Windows-only test release derived from PR #293. It does not replace
the v8.5.7 stable Linux/macOS/npm release. The Windows implementation is now
isolated under `platforms/windows/` and `lib/platforms/windows/`; prerelease
tags do not publish npm, Linux, macOS, sidebar, or Android artifacts.

### Included

- `ccb-windows-x86_64.zip` and a matching `.sha256` sidecar.
- Native PE launchers at `bin/ccb.exe`, `bin/ask.exe`,
  `bin/autonew.exe`, and `bin/ctx-transfer.exe`.
- A PowerShell installer that validates an optional archive checksum, validates
  the ZIP payload shape, installs the native launchers, and smoke-checks
  `ccb.exe --print-version`.
- The Herdr Windows backend, bootstrap, transport, release projection, tooling,
  and documentation in Windows-owned source folders.

### Install for testing

1. Download both Windows assets from this prerelease and verify the checksum:

   ```powershell
   Get-FileHash .\ccb-windows-x86_64.zip -Algorithm SHA256
   Get-Content .\ccb-windows-x86_64.zip.sha256
   ```

2. Extract the ZIP and run the installer from its payload root:

   ```powershell
   Expand-Archive .\ccb-windows-x86_64.zip -DestinationPath .\ccb-windows-beta
   cd .\ccb-windows-beta\ccb-windows-x86_64
   .\install.ps1 install -Yes
   ccb --print-version
   ```

### Prerequisites and known gaps

- Native Windows x64, Python 3.10+, WezTerm, Git Bash, and Herdr 0.8.0 or newer.
- This beta is not self-contained: `ccb.exe` is a native launcher for the
  packaged Python runtime source and requires a compatible system Python.
- `ccb update` is intentionally diagnostic-only in this first beta. Install a
  later beta by downloading and rerunning its validated `install.ps1`.
- The binaries are unsigned. Windows may show a SmartScreen warning.
- The first real Windows/WezTerm/Herdr qualification occurs in this prerelease
  lane. Report the exact command, redacted `ccb doctor --output`, and observed
  Pane behavior for failures.

### Validation boundary

Linux-side source, projection, archive, and installer contract tests are run
before tagging. GitHub Actions then performs the authoritative native Windows
x64 Rust build, PowerShell archive install, and `ccb.exe` smoke test. The
GitHub prerelease is created only after that Windows job succeeds.

## 中文

### 本预发布版本的用途

这是基于 PR #293 整理出的 Windows 专用测试版本，不会替代 v8.5.7 的
Linux/macOS/npm 稳定版。Windows 实现已集中到 `platforms/windows/` 和
`lib/platforms/windows/`；预发布标签不会发布 npm、Linux、macOS、Sidebar 或
Android 产物。

### 包含内容

- `ccb-windows-x86_64.zip` 及对应的 `.sha256` 校验文件。
- `bin/ccb.exe`、`bin/ask.exe`、`bin/autonew.exe` 和
  `bin/ctx-transfer.exe` 原生 PE 启动器。
- PowerShell 安装器：可校验 ZIP SHA256、验证压缩包结构、安装原生启动器，并执行
  `ccb.exe --print-version` 冒烟检查。
- Herdr Windows backend、bootstrap、transport、release projection、工具和文档均
  收纳到 Windows 专属源码目录。

### 测试安装

1. 从本预发布版本下载两个 Windows 资产并核对校验值：

   ```powershell
   Get-FileHash .\ccb-windows-x86_64.zip -Algorithm SHA256
   Get-Content .\ccb-windows-x86_64.zip.sha256
   ```

2. 解压 ZIP，在产物根目录运行安装器：

   ```powershell
   Expand-Archive .\ccb-windows-x86_64.zip -DestinationPath .\ccb-windows-beta
   cd .\ccb-windows-beta\ccb-windows-x86_64
   .\install.ps1 install -Yes
   ccb --print-version
   ```

### 前置条件与已知限制

- 原生 Windows x64、Python 3.10+、WezTerm、Git Bash，以及 Herdr 0.8.0 或更高版本。
- 本 Beta 并非完全自包含：`ccb.exe` 是原生启动器，负责启动包内 Python 源码，仍需
  兼容的系统 Python。
- 首个 Beta 中的 `ccb update` 会明确保持为仅诊断模式；升级后续 Beta 时，请重新
  下载并运行其经过校验的 `install.ps1`。
- 二进制尚未签名，Windows 可能显示 SmartScreen 提示。
- 本预发布通道会进行第一次真实 Windows/WezTerm/Herdr 验收。若失败，请提供准确
  命令、脱敏后的 `ccb doctor --output` 和 Pane 现象。

### 验证边界

打标签前会运行 Linux 侧源码、projection、压缩包和安装器契约测试。之后由 GitHub
Actions 完成权威的原生 Windows x64 Rust 构建、PowerShell 压缩包安装及
`ccb.exe` 冒烟测试；只有 Windows 作业成功后才会创建 GitHub Prerelease。
