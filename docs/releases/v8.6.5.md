# v8.6.5

Released: 2026-08-14

## English

### Highlights

- CCB Mobile Agent terminals now reconstruct tmux soft-wrapped rows as logical
  lines before reflowing them to the current device width. Long output remains
  readable in portrait and uses the wider landscape viewport without clipping
  its right edge or resizing the desktop-owned pane.
- Terminal prompt edits now update the active row in place. Repeated Backspace
  no longer leaves stale `xxxxx`, `xxxx`, and `xxx` rows in mobile scrollback.

### Fixes and reliability

- The terminal protocol now separates stable history from the mutable visible
  screen. Flutter replaces the projected screen for each edit and appends only
  rows that actually scroll off the source pane.
- The gateway retains backward-compatible repaint bytes for older clients,
  while current clients use structured snapshot fields and preserve the
  desktop tmux window and pane geometry across rotation and keyboard changes.
- The Mobile connection-state regression test now waits for its explicit
  reconnect event instead of relying on a fixed 20ms loopback timing window.

### Upgrade notes

- No pairing or project-state migration is required. Upgrade both the CCB host
  and Android APK to activate the corrected terminal projection protocol.
- Install the host with `npm install -g @seemseam/ccb@8.6.5`, or run
  `ccb update` from an existing release-package installation. Android users can
  install `ccb-mobile-v8.6.5.apk` from this Release.

### Known limitations

- Agent terminal mode remains a responsive projection of an existing desktop
  tmux pane, not a second independently owned pseudo-terminal (PTY). A
  full-screen terminal user interface produced for desktop geometry may wrap
  on a narrow phone instead of recomputing its layout.
- Android is the validated Mobile release target. iOS/iPadOS remain
  source-supported. Native Windows x64 remains beta and ships unsigned
  launchers.

## 中文

### 版本亮点

- CCB Mobile 的 Agent 终端现在会先把 tmux 的软换行恢复为逻辑行，再按当前
  设备宽度重新排版。长输出在竖屏下保持可读，横屏会利用更宽的视口，不再截断
  右侧内容，也不会改变电脑端拥有的 pane 尺寸。
- 终端提示符编辑现在会原位更新当前行。连续按 Backspace 不再在手机滚动历史中
  留下 `xxxxx`、`xxxx`、`xxx` 等过期行。

### 修复与稳定性

- 终端协议现在把稳定历史与可变的当前屏幕分开。Flutter 会在每次编辑时替换投影
  屏幕，只有真正滚出源 pane 的行才会追加到历史。
- Gateway 继续保留兼容旧客户端的 repaint bytes；当前客户端改用结构化快照字段，
  并在旋转屏幕、打开或关闭键盘时保持电脑端 tmux window 与 pane 尺寸不变。
- Mobile 连接状态回归测试改为等待明确的重连事件，不再假设本机回环请求一定会在
  固定的 20ms 内完成。

### 升级说明

- 无需迁移配对信息或项目状态。请同时升级 CCB 主机与 Android APK，以启用修正后
  的终端投影协议。
- 主机可运行 `npm install -g @seemseam/ccb@8.6.5`；通过 Release 包安装的用户
  也可运行 `ccb update`。Android 用户可从本 Release 安装
  `ccb-mobile-v8.6.5.apk`。

### 已知限制

- Agent 终端仍是现有电脑端 tmux pane 的自适应投影，并非手机独立拥有的第二个
  pseudo-terminal（PTY）。按电脑端尺寸绘制的全屏 TUI 在窄屏手机上可能换行，
  而不会重新计算布局。
- Android 是经过验证的 Mobile 发布目标；iOS/iPadOS 仍为源码支持。原生 Windows
  x64 仍处于 beta，且启动器尚未签名。
