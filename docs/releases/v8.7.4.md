# v8.7.4

Released: 2026-09-29

## English

### Conversation continuity

- Claude now attempts its Agent-owned local history after account, API key, or gateway changes instead of treating an authentication fingerprint change as a reason to start empty. Explicit fresh sessions and user-selected session controls still take precedence.
- Codex preserves a validated current native session across credential and route changes. It rebinds the authority generation and resumes the same conversation instead of unnecessarily demoting the binding to a fork or linked fresh session.
- Preserve conversation identity and generation metadata when session records are rewritten. Fresh startup does not accidentally inherit the previous native binding. Claude's recognized missing-conversation fallback retains historical evidence and a reason; authentication, network, and rate-limit failures do not trigger context clearing.
- Pi records manual session switches and completed turns so reopening selects the current observed conversation, not an older persisted binding. Explicit restore disablement remains effective during automatic restart.
- OMP accepts its newer typed title slot before the native session header, avoiding false restore rejection while preserving identity, work-directory, and managed-path checks.
- Refresh the public WeChat group QR image.

### Verification and upgrade

- 402 combined regression and native checks passed. Real Codex 0.157.1, Pi 0.87.1, and OMP 18.3.5 each preserved native identity across three process launches with changed loopback gateways and synthetic keys; the new endpoint received prior user and assistant history. Claude Code 2.1.283 also passed native history replay in the preceding qualification.
- Update CCB, then stop and reopen affected projects when their current work can safely be interrupted. Keep `.ccb` and Provider transcript files; no manual history migration is required. Existing working panes are not hot-upgraded.
- Android metadata follows the existing coordinated release pipeline. This release adds no mobile UI feature; platform support status is unchanged.

### Known limitations

- Native print/JSON and RPC tests do not establish a new interactive-pane or ask/FIFO end-to-end guarantee. Commercial OAuth accounts, remote-only conversations, and arbitrary gateways' tool/reasoning-history compatibility are not covered by loopback tests.
- Missing, corrupted, foreign, or already-lost current bindings are not blindly restored from historical records. Unsaved drafts and in-flight model operations are not recovered. Gemini authority-change handling remains unchanged.

## 中文

### 对话连续性

- Claude 在账号、API key 或中转地址变化后，优先尝试恢复当前 Agent 自有的本地历史，不再因认证指纹变化直接开启空对话。用户明确选择全新对话或指定会话时，仍以用户选择为准。
- Codex 在凭据、路由变化后保留已验证的当前原生会话，更新认证代次后继续同一对话，避免不必要地降级为 fork 或仅关联旧历史的空会话。
- 重写会话记录时保留对话身份和代次信息；全新启动不会误继承旧原生绑定。Claude 确认原生会话不存在后的降级会保留历史证据及原因；认证、网络和限流失败不会触发上下文清空。
- Pi 记录手动会话切换及已完成回合，重新打开时选择当前观测到的对话，而非过时绑定；明确禁用恢复的设置在自动重启时仍有效。
- OMP 支持新版原生会话头前的特定标题记录，避免有效历史被误判，同时保留身份、工作目录和受管路径检查。
- 更新公开微信群二维码。

### 验证与升级

- 402 项组合回归及原生检查通过。真实 Codex 0.157.1、Pi 0.87.1、OMP 18.3.5 均完成三次进程启动，在切换本地模拟中转和测试 key 后保持原生会话身份，新接口收到既有用户消息与助手回复。此前真实 Claude Code 2.1.283 也通过了原生历史回放验证。
- 更新 CCB 后，在当前工作可安全中断时停止并重新打开受影响项目。保留 `.ccb` 和 Provider 历史文件，无需手动迁移；已有工作 pane 不会被热更新。
- Android 元数据沿用现有同步发布流程。本版没有新增手机界面功能，各平台支持状态保持不变。

### 已知限制

- 原生 print/JSON 和 RPC 测试不代表新增了交互 pane 或 ask/FIFO 端到端保证。本地模拟测试未覆盖商业 OAuth 账号、仅保存在远端的会话，以及任意中转对工具/推理历史的兼容性。
- 缺失、损坏、越界或已丢失的当前绑定不会盲目从旧记录恢复；未提交草稿和进行中的模型操作不在恢复范围内。Gemini 的账号变化处理保持不变。
