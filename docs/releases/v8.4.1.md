# CCB v8.4.1

Released: 2026-07-26

## English

### Release installer reliability

- Official Linux and macOS release installs now keep Python packages in a
  CCB-managed virtual environment.
- A system Python without pip can still install CCB when it supports `venv`;
  watchdog, aiohttp, and cryptography are installed inside CCB's own
  environment.
- Interrupted package downloads retry on the same index when no fallback
  package index is configured.

### Upgrade notes

- No project or mobile pairing migration is required.
- npm-managed installations can run
  `npm install -g @seemseam/ccb@8.4.1`.
- Users retrying a failed v8.4.0 update can temporarily run it with
  `CCB_USE_MANAGED_VENV=1`; v8.4.1 enables that behavior by default.

## 中文

### Release 安装器可靠性

- Linux 和 macOS 正式版安装现在都会把 Python 依赖保存在 CCB 自己管理的
  虚拟环境中。
- 即使系统 Python 没有 pip，只要支持 `venv`，仍可安装 CCB；watchdog、
  aiohttp 和 cryptography 会安装到 CCB 自己的环境，不会污染系统 Python。
- 未配置备用软件源时，安装器会对下载中断类错误在同一软件源上自动重试。

### 升级说明

- 不需要迁移项目或手机配对数据。
- npm 安装可执行：
  `npm install -g @seemseam/ccb@8.4.1`。
- 正在重试 v8.4.0 失败更新的用户可临时设置
  `CCB_USE_MANAGED_VENV=1`；v8.4.1 已默认启用该行为。
