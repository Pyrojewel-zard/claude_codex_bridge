# v8.6.7

Released: 2026-08-16

## English

### Highlights

- CCB Mobile can now use a user-selected image as the full-screen workspace
  background across the project header, agent chat, composer, Agent Terminal,
  and standalone Computer Terminal.
- Background images are selected from the existing settings surface, with
  preview, replacement, and removal controls. Terminal views keep a stronger
  readability scrim while preserving terminal text contrast.

### Fixes and reliability

- Background rendering is attached to the workspace shell, so switching
  between chat and terminal modes does not lose the selected image or require a
  reconnect.
- Images are validated by file signature, limited to 20 MiB, copied to private
  app storage, and never uploaded to the CCB gateway or Relay.
- The release validation covered the full Flutter suite (`785 passed, 1
  skipped`), static analysis, release APK build, Android Emulator startup,
  chat, Agent Terminal, standalone Computer Terminal, persistence, and
  removal.

### Upgrade notes

- Upgrade the CCB host and CCB Mobile APK to `v8.6.7` together. No pairing,
  conversation, or project migration is required.
- Existing installations keep their normal theme until an image is selected in
  the workspace settings. Removing the image immediately restores the normal
  theme surface.

### Known limitations

- Android is the validated Mobile release target; iOS/iPadOS remain
  source-supported. The selected image is local to each phone and is not
  synchronized between devices.

## 中文

### 版本亮点

- CCB Mobile 现在可以使用用户选择的图片作为全屏工作区背景，覆盖项目头部、
  Agent 对话、输入框、Agent 终端以及独立电脑终端。
- 现有设置页面新增背景图预览、替换和移除操作。终端模式会保留更强的可读性遮罩，
  同时保持终端文字对比度。

### 修复与稳定性

- 背景图挂载在工作区外壳上，在聊天和终端模式之间切换时不会丢失，也不需要重新连接。
- 图片会按文件签名校验，大小限制为 20 MiB，复制到应用私有存储，并且不会上传到
  CCB 网关或 Relay。
- 发布验证覆盖完整 Flutter 测试套件（`785 passed, 1 skipped`）、静态分析、Release
  APK 构建、Android 虚拟机启动、聊天、Agent 终端、独立电脑终端、重启恢复和移除。

### 升级说明

- 请将 CCB 主机和 CCB Mobile APK 一起升级到 `v8.6.7`。不需要迁移配对信息、对话或项目。
- 已有安装在设置中选择背景图之前会继续使用普通主题；移除背景图后会立即恢复普通主题界面。

### 已知限制

- Android 是经过验证的 Mobile 发布目标；iOS/iPadOS 仍为源码支持。背景图只保存在每台
  手机本地，不会在设备之间同步。
