# v8.5.5

Released: 2026-08-05

Status: Withdrawn from GitHub on 2026-08-05 because first startup treated all
legacy sessions without the new authority marker as incompatible. Codex moved
those sessions outside the active `resume` namespace, while Claude and Gemini
suppressed continuation. The package version must not be used for managed
session upgrades.

## English

### Highlights

- Provider account and API changes now take effect through
  `ccb restart <agent>`. Restart rebuilds the managed launch from the current
  Provider profile, login, API key, endpoint, proxy, and model state instead of
  replaying the command saved when the pane was first created. `ccb clear` is
  no longer required after switching authority.
- Session continuation is fenced by an Agent-private HMAC fingerprint. Codex
  archives an incompatible managed binding and starts fresh; Claude and Gemini
  suppress native resume when the saved session belongs to another authority.
  Raw credentials are never written to session metadata.

### Fixes and reliability

- Legacy managed sessions without an authority fingerprint start a fresh
  conversation once. Provider login state and history files are preserved.
- New Relay Host invitations default to 1 GiB per 24-hour quota window instead
  of 200 MiB. Explicit `--max-bytes-per-day` overrides and existing Host
  credentials keep their configured quota.
- The WeChat community QR image and its README cache key were refreshed.

### Upgrade notes

- No configuration or data migration is required. After changing an account,
  API key, endpoint, proxy, or model profile, run `ccb restart <agent>` for each
  affected managed Agent.
- Install the npm package with
  `npm install -g @seemseam/ccb@8.5.5`. Android users can install the signed
  CCB Mobile v8.5.5 APK from this release.

### Validation notes

- The focused Provider authority, restart, and Relay regression suite passed 172
  tests. The broader local suite reported 6123 passed, 2 skipped, and 5 Role
  workflow failures because the local `agent-roles` executable was unavailable;
  one of those failures also reported related process residue.

## 中文

状态：已于 2026-08-05 从 GitHub 撤回。首次启动会把所有缺少新 authority
marker 的旧会话误判为不兼容；Codex 会把这些会话移出 `resume` 可见的活动目录，
Claude 和 Gemini 则会禁止续接。该包版本不应再用于托管会话升级。

### 版本亮点

- Provider 账号与 API 状态切换后，现在执行 `ccb restart <agent>` 即可生效。
  restart 会根据当前 Provider profile、登录状态、API key、endpoint、proxy 和
  model 重新构建托管启动命令，不再复用 pane 初次创建时保存的旧命令，因此
  无需再执行 `ccb clear`。
- 会话续接现在由 Agent 私有的 HMAC 指纹隔离。Codex 会归档不兼容的托管绑定
  并新建会话；Claude 和 Gemini 检测到已保存会话属于其他权威状态时，会禁止
  原生 resume。会话元数据不会写入原始凭据。

### 修复与稳定性

- 旧版托管会话如果没有权威指纹，只会一次性新建对话；Provider 登录状态和
  历史文件都会保留。
- 新签发的 Relay Host 邀请默认配额从每 24 小时 200 MiB 提升到 1 GiB。
  显式指定的 `--max-bytes-per-day` 以及现有 Host 凭据的配额保持不变。
- 微信社区群二维码及 README 缓存 key 已刷新。

### 升级说明

- 无需迁移配置或数据。更换账号、API key、endpoint、proxy 或 model profile
  后，对每个受影响的托管 Agent 执行 `ccb restart <agent>`。
- npm 安装命令为 `npm install -g @seemseam/ccb@8.5.5`。Android 用户可从本
  Release 安装签名后的 CCB Mobile v8.5.5 APK。

### 验证说明

- Provider 权威状态、restart 与 Relay 的重点回归共 172 个测试通过。更大范围的本地
  测试结果为 6123 个通过、2 个跳过、5 个 Role workflow 失败；失败原因是本机
  缺少 `agent-roles` 可执行文件，其中 1 项同时报告了相关进程残留。
