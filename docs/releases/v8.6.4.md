# v8.6.4

Released: 2026-08-14

## English

### Highlights

- CCB Mobile Agent terminals now adapt to the device viewport instead of
  reproducing the desktop tmux pane width. Text remains readable in portrait
  and uses the additional columns available in landscape, while the desktop
  pane keeps its original geometry.
- Agent terminals open inline in a full-width workspace on phone and wide
  layouts. Terminal font size and shortcut visibility/order are managed from
  one persistent Terminal settings panel.

### Fixes and reliability

- LAN and Relay terminal sessions now coalesce concurrent reconnect attempts,
  discard stale WebSocket and Relay stream handles safely, and recover without
  allowing an old connection to remove its replacement.
- The gateway publishes authoritative source-pane geometry, ignores phone
  resize requests for desktop-owned Agent panes, repaints snapshots safely for
  local reflow, and closes active terminal sessions during service shutdown.
- Touch handling no longer mistakes multi-touch terminal gestures for input
  activation, and terminal-generated device reports are filtered without
  dropping ordinary user input.
- Windows Herdr can reattach persisted namespace and pane references after a
  restart. Persisted capability evidence is intersected with a stricter live
  report when one is available, so recovery remains fail-closed (PR #304).

### Upgrade notes

- No pairing or project-state migration is required. Upgrade both the CCB host
  and the Android APK to use the complete terminal viewport protocol.
- Install the host with `npm install -g @seemseam/ccb@8.6.4`, or run
  `ccb update` from an existing release-package installation. Android users can
  install `ccb-mobile-v8.6.4.apk` from this Release.

### Known limitations

- Agent terminal mode is a responsive projection of an existing desktop tmux
  pane, not a second independently owned pseudo-terminal (PTY). Full-screen
  terminal user interfaces and box-drawing output produced for the desktop
  width may wrap on a narrow phone instead of recomputing their layout.
- Android is the validated Mobile release target. iOS/iPadOS remain
  source-supported. Native Windows x64 remains beta and ships unsigned
  launchers.

## 中文

### 版本亮点

- CCB Mobile 的 Agent 终端现在会适配设备视口，不再按电脑端 tmux pane
  宽度原样投影。竖屏下文字保持可读，横屏会使用更多列，同时电脑端 pane
  始终维持原有尺寸。
- 手机和宽屏布局都可在当前 workspace 内以全宽方式打开 Agent 终端。终端字号、
  快捷键显示与顺序统一在可持久化的终端设置面板中管理。

### 修复与稳定性

- LAN 和 Relay 终端会合并并发重连，安全清理过期 WebSocket 与 Relay stream，
  防止旧连接在退出时误删已经建立的新连接。
- Gateway 会发布权威的源 pane 尺寸，拒绝手机改变电脑端 Agent pane，使用适合
  本地重排的完整快照刷新，并在服务退出时关闭所有活跃终端 session。
- 多指终端手势不再被误判为输入激活；终端自动生成的设备响应会被过滤，同时保留
  普通用户输入。
- Windows Herdr 现在可在重启后重新挂接已经持久化的 namespace 与 pane 引用；如果
  存在更严格的在线能力报告，会与持久化能力取交集，继续保持 fail-closed（PR #304）。

### 升级说明

- 无需迁移配对信息或项目状态。请同时升级 CCB 主机与 Android APK，以使用完整的
  terminal viewport 协议。
- 主机可运行 `npm install -g @seemseam/ccb@8.6.4`；通过 Release 包安装的用户
  也可运行 `ccb update`。Android 用户可从本 Release 安装
  `ccb-mobile-v8.6.4.apk`。

### 已知限制

- Agent 终端是现有电脑端 tmux pane 的自适应投影，并非手机独立拥有的第二个
  pseudo-terminal（PTY）。针对电脑宽度绘制的全屏 TUI 和框线内容，在窄屏手机上
  可能换行，而不会由 Provider 重新计算布局。
- Android 是经过验证的 Mobile 发布目标；iOS/iPadOS 仍为源码支持。原生 Windows
  x64 仍处于 beta，且启动器尚未签名。
