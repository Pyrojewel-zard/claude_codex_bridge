# CCB v8.4.2

Released: 2026-07-27

## English

### Config UI and appearance

- The sidebar settings button now recovers from stale inherited Python paths
  and opens Config UI with CCB's release-managed interpreter.
- Config UI now provides a persistent Appearance selector for the supported CCB
  themes, including system-default behavior.
- The saved theme is authoritative after restart, so Rich WezTerm and the
  sidebar no longer replace it with stale process environment.

### Mobile Relay and pairing

- Relay terminal streaming now applies bounded backpressure and sends stable
  initial snapshots and incremental updates, including correct handling for
  wide characters.
- High-density pairing payloads and narrow terminals now fall back to a
  scannable PNG instead of wrapped terminal QR art. The temporary PNG is
  created with owner-only permissions.

### Provider update safety

- npm-owned providers update through the detected user or NVM prefix instead
  of accidentally targeting a different global installation.
- Bun-owned providers keep their detected Bun home and `BUN_INSTALL` value.
- Non-writable system installations and registry releases that resolve to
  local package dependencies are reported without attempting an unsafe update.

### Upgrade notes

- No project or mobile pairing migration is required.
- npm-managed installations can run
  `npm install -g @seemseam/ccb@8.4.2`.
- Android users can install the signed CCB Mobile v8.4.2 APK from this release.

## 中文

### Config UI 与外观

- 侧边栏左上角设置按钮现在会避开继承到的失效 Python 路径，使用 CCB
  正式版自带的受管 Python 打开 Config UI。
- Config UI 新增可持久化的“外观”选择器，可选择 CCB 支持的主题，也可跟随
  系统默认主题。
- 重启后以已保存的主题为准，Rich WezTerm 和侧边栏不会再被旧进程环境中的
  主题值覆盖。

### 手机 Relay 与配对

- Relay 手机终端流现在支持有界背压、稳定的初始快照和增量屏幕更新，并能
  正确计算中日韩等宽字符，避免输出丢失或画面损坏。
- 当配对内容密度过高或终端过窄时，CCB 会生成可直接扫描的 PNG，而不是
  输出折行后无法识别的终端二维码；临时 PNG 仅允许当前用户访问。

### Provider 更新安全性

- npm 管理的 Provider 会沿用检测到的用户级或 NVM 安装前缀更新，避免误写
  到另一个全局安装位置。
- Bun 管理的 Provider 会保留检测到的 Bun 主目录和 `BUN_INSTALL`。
- 对不可写的系统安装，以及解析到本地包依赖的异常 Registry 版本，CCB
  只报告更新信息，不执行不安全的安装。

### 升级说明

- 不需要迁移项目或手机配对数据。
- npm 安装可执行：
  `npm install -g @seemseam/ccb@8.4.2`。
- Android 用户可从本 Release 安装签名后的 CCB Mobile v8.4.2 APK。
