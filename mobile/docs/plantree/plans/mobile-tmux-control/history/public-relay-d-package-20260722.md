  registration, PoP signing, host X25519 fingerprint confirmation, v2

  low-sensitive diagnostics.

## Residual Risks

- Terminal streaming over the relay is represented by the Flutter
  `terminal_frames`/`send_terminal_frame` operation surface but still requires
  a host-side long-lived terminal WebSocket pump before full terminal
  acceptance.
- Fresh rendezvous issuance for every new phone relay session still needs the
  final pairing/update integration point. Persisted pairing remains reusable,
  but one-time relay rendezvous material must not be treated as reusable across
  app restarts.
